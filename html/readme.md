# Warp 4 Script 仕様書
## キーワード
### 変数
var.set 名前 (値)
・自由に名前も値も設定可能
・いつでも呼び出して定義可能
・グローバル

var.edit 名前 (値)
・再代入haeditでなければならない
・setで再代入はスキップされる

### 定数
const.set 名前 (値)
・自由に名前も値も設定可能
・再代入はありません
・グローバル

### 関数
#### 定義
fun (名前) {
    プログラム内容
}
・重複定義は不可能
#### 使用
fun (名前)
・いつでも呼び出せる
・引数などは一切ないので変数を介す必要がある

### 条件分岐
#### 一致
if 何か = 何か {
    プログラム
}
・何かには変数でも計算でもなんでも入れることができる
・プログラムは幾つでも実行可能です
#### 一致しない
if 何か != 何か {
    プログラム
}
・何かには変数でも計算でもなんでも入れることができる
・プログラムは幾つでも実行可能です
#### 数値比較
if 何か < 何か {
    プログラム
}
・何かには変数でも計算でもなんでも入れることができるが，内容は数値に限る
・比較不可能だった場合はスキップされる
・プログラムは幾つでも実行可能です
・>も利用可能

### 繰り返し
for (関数名)
・breakが呼び出されるまで永遠に関数が繰り返される

### 繰り返し終了
break
・これが呼び出されたらその繰り返しは終了する
・繰り返しがないときに関数などから呼び出されても何も起こらない

### 出力
print(内容)
・内容をただ出力する

### 待機
wait(単位付き時間)
・1msや1sなどで指定できます
・待機中は何もせずにただ待つだけです

### コメント
#内容
・#以降をコメントとします。

## 特殊
・var[...] const[...] や calc[...]は絶対にどこでも呼び出せます

### 究極の例
var.set key (print)
var[key] (Hello)
・これでも正しくprint (Hello)と認識されますこのレベルでも可能でとにかくどこでも展開されなければなりません

### 変数と定数
var.set name (world)
var.set message (Hello, var[name])
・結果的に変数messageにはHello, worldと定義されます
・varでもconstでも値を変えれば可能です

var.set name (update)
if 何か = 何か (fun var[name])
これでも正常にupdate関数を呼び出すことができます

### 計算
var.set age (10)
var.set r1 (calc[var[age] + 1])
・結果的に変数r1に11と定義されます
・calcがない限りは計算できると認識されません

var.set age (1 + 2)
var.set r1 (var[age])
var.set r2 (calc[var[age]])
・結果的に変数r1には1 + 2とそのまま定義され，r2には3と結果が定義されます

## WarpUIキーワード
・上記仕様は全て適用されます
### 値の変更
WarpUI.text ID (内容)
・指定したIDの中のテキストを置き換えることができます
WarpUI.textColor ID (内容)
・指定したIDの文字色を変更可能です
WarpUI.background ID (内容)
・指定したIDの背景色を変更可能です
WarpUI.textSize ID (内容)
・指定したIDの文字サイズを指定可能です

・その他layout_heightや相対移動なども全て指定可能です
### 表示状態
WarpUI.visibility ID (visible)
WarpUI.visibility ID (invisible)
WarpUI.visibility ID (gone)
・Androidと変わりません
### 動作
WarpUI.OnClick ID {
    プログラム
}
・クリックされた時に呼び出されます

WarpUI.editText ID (何か)
・指定された値にテキストボックスの値が変わりますクリアにしたいならば何かに何も指定しなければいいです

WarpUI.getText ID (変数名)
・指定された変数名に指定のIDのテキストボックスの内容がセットされます
・変数は事前に定義されていなければなりません
