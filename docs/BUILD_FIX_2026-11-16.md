# Rust build fixes — 2026-11-16

This patch fixes the diagnostics reported when compiling `mb5-runner`.

## `src/canvas.rs`

The gradient interpolation uses the physical/logical width as `f32`. The clamp bounds and width comparison now use floating-point literals (`0.0`, `1.0`), and the integer pixel offset is converted to `f32` before clamping. This preserves the existing linear-gradient interpolation while satisfying the type requirements.

## `src/app.rs`

`draw_container` now copies the fixed-size `Text<16>` component-kind field into a local value before obtaining its byte slice. Recursive calls to `draw_component` mutably borrow `self`; the local copy prevents the kind slice from holding an immutable borrow through those calls.

## `src/project.rs`

Removed redundant parentheses around the list/navigation/dropdown/tab condition.

## Validation

`sh tools/mb5/check.sh` passed the MB5 project lint, C VM tests, and script syntax/callback checks. The script skipped `cargo check` because Cargo/Rust are not installed in the patching environment. Run `cargo check --manifest-path runner/rust/Cargo.toml` on the target Mac to verify the Rust host integration.


## Startup segmentation-fault hardening

The project model has a large fixed-capacity footprint (roughly 2.9 MiB on 64-bit targets). Previously it was created on `main`'s stack and then moved by value into `App`, which could exhaust the default macOS main-thread stack before the window appeared. `PROJECT` now lives in static storage and `App` holds an exclusive reference to it, eliminating those large stack copies.

The script VM also previously placed its command-word array (about 96 KiB) and each procedure's local-variable frame (about 130 KiB) on the native stack. Those allocations are now heap-backed and checked for allocation failure. A nested procedure regression case was added to the C VM tests.

On the target Mac, rebuild from source before launching: `sh runner/rust/run.sh`. To isolate rendering from AppKit window startup, use `sh runner/rust/run.sh --ppm > /tmp/mb5-preview.ppm`. If the PPM mode still terminates with signal 11, the fault is in project parsing, font initialization, script startup, or software rendering rather than the AppKit window backend. If only normal window mode fails, capture a macOS crash report for the AppKit/CoreGraphics backend.

The AppKit bridge's Objective-C message wrappers were also aligned with the real method signatures: void-returning BOOL setters use a void-return wrapper, while `setActivationPolicy:` uses its BOOL return and NSInteger argument signature.
